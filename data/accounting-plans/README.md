# Référentiels comptables

Déposer les documents sources par référentiel :

- `pcg/` : Plan Comptable Général français
- `syscohada/` : SYSCOHADA révisé
- `autres/` : autres référentiels comptables

Les PDF volumineux restent des sources de référence. Ils seront analysés puis convertis en données structurées après vérification du format et de la version du référentiel.
